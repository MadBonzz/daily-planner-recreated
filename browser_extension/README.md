# Block websites during a running task

1. Run Plan Smarter locally. Open **Options → Planner settings → Browser blocking**, then choose **Enable browser blocking for your personal planner**. In an editable Dev history, the same control binds just that history instead.
2. In Chrome open `chrome://extensions`. In Edge open `edge://extensions`. Turn on **Developer mode**, select **Load unpacked**, and choose the repository’s `browser_extension` directory (the folder containing `manifest.json`). This uses the browser profile and requires no system-wide installation. A managed browser can restrict unpacked extensions. [Chrome setup](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked) · [Edge setup](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)
3. Reveal and copy the pairing code from Planner settings. Open **Plan Smarter • Focus sites** from the browser’s Extensions menu, paste the code, and select **Pair browser**. Repeat in each profile you want to use. The planner shows how many connected profiles have confirmed its rule list.
4. Open **Websites to block during this task** on an unfinished task. Kev can suggest a domain after a single off-task visit on related work. The card shows the historical task, duration and available window title. If a custom visit has no Kev decision yet, you can select the domain yourself or choose **Re-estimate** with Kev running. Repeated distractions on multiple related tasks also qualify. Remove a suggestion or enter your own domain, then select **Save websites**. Task-specific edits survive a re-estimate.
5. Start or resume the task. The extension blocks new top-level visits to the selected sites, including subdomains, and moves already-open matching tabs to a local **Website paused** page. On pause, stop, switch, completion, deletion or a list edit, it releases sites that are no longer selected. A parked tab returns to its previous address if you left it on the pause page. Browsers may show their own blocked-request page on a new visit; retry that address after release.

**Workspace selection.** One workspace controls the paired profiles. Viewing another history does not rebind them. To try a Dev task, enable blocking explicitly in that editable history. Rebind the personal planner when finished. Resetting a bound sample releases its rules until you bind the replacement. Chronological replay cannot control a browser.

**Connection and privacy.** The extension talks only to the planner’s loopback listener at `127.0.0.1:47843` using its pairing code. The planner sends the effective domains and a change fingerprint. It receives a random browser-profile ID and the fingerprint of the last rule list applied. The extension checks tabs locally. Original addresses of already-open sites are held in browser session storage so those tabs can be restored. URLs, tab titles, task names and activity logs are never sent over the pairing connection.

A paired profile checks committed timer and forecast changes while the planner process runs, including when the dashboard tab is closed. The Chrome/Edge extension uses temporary session rules. Disconnection clears rules and restores parked tabs when the connection check fails, ordinarily within 22 seconds while the browser is awake. Sleeping or suspended browsers can delay checks until they wake. Session rules clear on browser shutdown. If the planner process restarts, open its dashboard once to start the pairing listener again. **Disconnect and release sites** in the extension releases one profile. **Disconnect all browsers and release sites** in Planner settings revokes the code for every profile. Other browsers, devices and applications are outside this extension’s scope. [Browser rules](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest) · [Worker lifecycle](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)

To smoke-test locally, add a harmless site such as `example.org` to a task, open the site, and start the timer. Check that the tab is parked and a new visit is blocked. Pause, check that the original tab returns, and resume once more. Close the planner process while the timer runs to test release on disconnect.
